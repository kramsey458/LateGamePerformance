Install guide

About five minutes. You need Timberborn 1.1 and two other mods, Harmony and Mod Settings.

Back up first. It is a young mod, so try it on a copy of your save.

Requirements

  • Timberborn 1.1, version 1.1.2.4 or newer. What a game update can do.
  • Harmony 2.4.1 or newer and Mod Settings, both from the Steam Workshop. Enable them in the game's Mods menu along with this mod.
  • The folders shown on this page are the Windows ones.

Step by step

  1. Back up your save

    Copy the save you want to use from Documents\Timberborn\Saves.

  2. Get Harmony and Mod Settings

    Subscribe to Harmony and Mod Settings on the Steam Workshop. This mod won't start without them.

  3. Download the mod

    Get LateGamePerformance-0.4.30.zip from the release page, under Assets, not Source code.

    A preview, when there is one, is on the same Releases page marked Pre-release. It installs the same way but hasn't been played yet.

  4. Close Timberborn

    Make sure the game is fully closed before you copy files into its Mods folder.

  5. Extract into your Mods folder

    Delete any older LateGamePerformance folder. Then extract the ZIP into Documents\Timberborn\Mods. You should get one LateGamePerformance folder, as in the layout below.

  6. Enable it and restart

    Start Timberborn, open Mods from the main menu, tick Harmony, Mod Settings and Late Game Performance, and restart the game when it asks.

  7. Playing co-op? Every player does the same

    Every player installs the same version, and you update together. More on multiplayer

  8. Load your save and play

    The mod works as soon as a game loads. Check that it's running.

Check that it works

The game log shows whether the mod is running.

  1. Quit the game, then open %USERPROFILE%\AppData\LocalLow\Mechanistry\Timberborn\Player.log. If you have already restarted, the previous session is in Player-prev.log.
  2. Search for [LateGamePerformance]. At startup you should see a line for the version and one for the features: 
    [LateGamePerformance] 0.4.30 loading.[LateGamePerformance] Simulation features: HaulCache on, RouteMaps on, YielderSearch on, TerrainMaps on, PlantWater on, DistrictCounts on, WaterMapCopy on, SoilScans on, TerrainSearch on, IdleEntities on, HomeSearch on, Reachability on. These are the same for every player on this version.
  3. Another startup line reports the garbage collector. GC: incremental=False means memory clean-ups stop the whole game while they run. You can change that.
  4. While you play, stats lines starting Last 1000 ticks. appear every 1,000 ticks (10 minutes at normal speed).

No lines, or a line that says OFF? Head to Troubleshooting.

Turn on incremental garbage collection

Optional. The game cleans up memory with everything stopped. In a late-game colony that can freeze it for most of a second, about once a minute. Incremental collection does the same work a few milliseconds at a time.

  1. Open Mods → Late Game Performance, from the main menu or in game.
  2. Tick Incremental garbage collection.
  3. Restart the game. The startup line should now say GC: incremental=True.

Ticking the box adds one line to the game's boot.config file and saves a backup first. Why, and is it safe? Still False? See Troubleshooting.

Multiplayer

Every player installs the same version of the mod and runs the same game version. Nothing else has to match, because nothing that affects the simulation is a setting (which settings may differ).

The Simulation features: startup line (above) should read the same in every player's Player.log. If one player's line says OFF, see Troubleshooting.

Updating

  1. Close the game and delete the old Mods\LateGamePerformance folder.
  2. Extract the new ZIP into Mods as above.
  3. Start the game. If you copied back an older LateGamePerformance.cfg, keys the mod doesn't use are ignored.
  4. In multiplayer, every player updates to the same version together.

Uninstalling

Untick it in the Mods menu and restart, or delete the LateGamePerformance folder. The mod stores nothing in saves. If you ticked Incremental garbage collection, untick it first: that takes its line out of boot.config.

Verify the download (optional)

In PowerShell, from the folder you downloaded to:

Get-FileHash .\LateGamePerformance-0.4.30.zip -Algorithm SHA256

The hash should be:

3393e5ab701eee5c5eedd38e9caf0880131c0db223d6f3ff2ddb247e7a45ccb7
